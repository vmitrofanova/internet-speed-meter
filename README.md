# Internet Speed Meter

Простой консольный замер скорости скачивания без сторонних зависимостей. Скрипт
последовательно отправляет 10 HTTP(S)-запросов по указанному адресу, полностью
читает каждый ответ и выводит:

- время и скорость каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- среднюю скорость загрузки в МБ/с.

> **Важно:** URL будет скачан 10 раз. Выбирайте публичный файл, для которого у вас
> есть разрешение на такую нагрузку. Например, файл размером 20 МБ создаст около
> 200 МБ трафика.

## Требования

- Python 3.9 или новее;
- доступ к HTTP(S)-адресу тестового файла.

## Запуск

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone https://github.com/vmitrofanova/internet-speed-meter.git
cd internet-speed-meter
```

Передайте скрипту прямой URL тяжёлой картинки или другого файла:

```bash
python3 speed_meter.py "https://example.com/large-image.jpg"
```

По умолчанию выполняется ровно 10 последовательных запросов. Для отладки число
запросов и тайм-аут можно изменить:

```bash
python3 speed_meter.py "https://example.com/large-image.jpg" --requests 3 --timeout 60
```

Пример итогового вывода:

```text
Итого:
  Среднее время запроса: 1.245 с
  Скачано данных:        100.000 МБ (100000000 байт)
  Средняя скорость:      8.032 МБ/с
```

Здесь `МБ` — десятичные мегабайты: 1 МБ = 1 000 000 байт. Средняя скорость
рассчитывается как общий объём скачанных данных, делённый на суммарное время всех
запросов. DNS, установка соединения, TLS и полное чтение ответа входят во время
замера.

## Тесты

Тесты поднимают локальный HTTP-сервер и не используют интернет:

```bash
python3 -m unittest -v
```

## Справка

```bash
python3 speed_meter.py --help
```
