# Internet Speed Meter

Консольный инструмент на **Python 3.12** для воспроизводимого замера скорости
HTTP(S)-скачивания. По умолчанию он выполняет ровно 10 последовательных запросов
по указанному URL, полностью читает каждый ответ и только после этого начинает
следующий запрос.

## Что измеряется

- время и скорость каждого запроса;
- среднее время запроса;
- общий фактически скачанный объём;
- средняя скорость всей серии в МБ/с.

Время запроса включает DNS, установку TCP-соединения, TLS, получение заголовков
и полное чтение тела ответа. Объём считается по реально прочитанным байтам, а не
по заголовку `Content-Length`. `1 МБ = 1 000 000 байт`.

> **Важно:** файл скачивается 10 раз. Например, URL файла размером 20 МБ создаст
> около 200 МБ трафика. Используйте адрес, для которого такая нагрузка допустима.

## Требования

- CPython 3.12.x;
- доступ к HTTP(S)-адресу тестового файла;
- сторонние библиотеки для запуска не нужны.

## Быстрый запуск

```bash
git clone https://github.com/vmitrofanova/internet-speed-meter.git
cd internet-speed-meter
python3.12 speed_meter.py "https://example.com/large-image.jpg"
```

Альтернативно можно установить CLI в изолированное окружение:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install .
speed-meter "https://example.com/large-image.jpg"
```

Число запросов и тайм-аут можно изменить для диагностики:

```bash
python3.12 speed_meter.py \
  "https://example.com/large-image.jpg" \
  --requests 3 \
  --timeout 60
```

Пример итогового вывода:

```text
Итого:
  Среднее время запроса: 1.245 с
  Скачано данных:        100.000 МБ (100000000 байт)
  Средняя скорость:      8.032 МБ/с
```

Средняя скорость считается как `общий объём / суммарное время`. Это взвешенная
оценка всей серии, в отличие от среднего арифметического скоростей отдельных
запросов, которое искажает результат при разной длительности запросов.

Это замер пропускной способности маршрута именно до выбранного сервера, а не
абсолютная характеристика интернет-подключения. На результат влияют сервер,
CDN, маршрут, DNS и TLS. Для устойчивого результата выбирайте достаточно большой
статический файл на быстром сервере и не нагружайте сеть другими загрузками.

## Архитектура и инженерные решения

Код разделён по ответственности:

- `config.py` — валидированная конфигурация;
- `http.py` — потоковое HTTP-скачивание и монотонный таймер;
- `domain.py` — неизменяемые результаты и правила агрегации;
- `service.py` — строго последовательная оркестрация серии;
- `cli.py` — парсинг аргументов и форматирование вывода.

Тело ответа читается блоками по 64 КиБ, поэтому потребление памяти не зависит от
размера файла. Для измерения используется `perf_counter_ns()`. Если один запрос
не завершился, серия прекращается с ненулевым кодом выхода: частичные данные не
выдаются за полноценный результат. Заголовок `Accept-Encoding: identity`
исключает неоднозначность между сжатым и распакованным объёмом.

Транспорт внедряется через `Protocol`, поэтому бизнес-правила тестируются без
сети, а отдельный интеграционный тест проверяет реальное потоковое чтение с
локального HTTP-сервера.
